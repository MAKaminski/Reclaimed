# Reclaimed — Claude working notes

Georgia unclaimed-property recovery for a registered CDR. **The compliance layer is the
product**: O.C.G.A. § 44-12-239.2 sanctions twelve acts at up to $2,000 each, and three of them
are easy to commit from ordinary product code. Read `docs/BUILD-SPEC.md` §1 before touching
anything that moves money, generates an agreement, or sends a message.

## Layers

| Layer | Where | Rule that bites |
|---|---|---|
| Front-end | `app/(public)` static, indexable · `app/(staff)`, `app/(auth)` dynamic, noindex · `components/` | `(public)` may never import `@/lib/db` — CI fails |
| Back-end | Supabase Postgres, `db/migrations/` (33), RLS as the caller | a new table arrives with an FK or a written reason (ARCHITECTURE.md §7) |
| Middleware | `app/api/`, `lib/{claims,compliance,forms,ingest,locate,outreach,pipeline,scoring}`, `mcp/server.ts` | the solicitation legend has exactly one definition (`lib/compliance/legend.ts`) |
| Infrastructure | Next.js + pnpm, Vercel, `scripts/verify-*.ts` as CI gates | fifteen compliance gates in `pnpm verify:all` |

`ARCHITECTURE.md` (root) is generated by `/arch`; `docs/ARCHITECTURE.md` is the prose. Both
before adding a component or table. ADRs: `docs/DECISIONS.md` (twelve).

## Commands — scope-first

```bash
pnpm typecheck                      # first
pnpm test:compliance                # one named test per §1 guardrail — run after any compliance/outreach change
pnpm test tests/unit/<file>         # narrow; bare `pnpm test` is blocked by the guard hook
pnpm verify:<gate>                  # one gate; `verify:all` only before a PR
pnpm test:e2e tests/e2e/<spec>      # Playwright, narrow
```

A static gate is decoration until a negative probe proves it fires — `verify:templates` has
been fooled four times. When you add an assertion, break the code on purpose and confirm the
build fails.

## Do not

- Add Stripe or any payments integration (ADR-0001). `verify:no-payments` will fail anyway.
- Scrape `gaclaims.unclaimedproperty.com` or `ecorp.sos.ga.gov` (ADR-0001 §3).
- Put the legend on a public page, or add a contact form / waitlist before registration
  (ADR-0010; § 44-12-239.2(a)(5), (a)(10)).
- Backfill `property_workflow` to make dashboard counts look populated — it destroys
  `entered_stage_at`.
- Add a fourth copy of the stage order. There are already three.
- Build against DOR form UP-1061 (recites the repealed regime).
